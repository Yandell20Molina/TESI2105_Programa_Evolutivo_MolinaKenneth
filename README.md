# Registro de Observación Astronómica

## Problema que atiende
Este programa permite registrar de manera sencilla una sesión de observación astronómica y calcular el tiempo dedicado a la actividad.

## Usuario principal
Personas interesadas en la astronomía y la observación del espacio.

## Descripción
El Registro de Observación Astronómica es un programa sencillo creado en Python. El usuario podrá ingresar información básica sobre una observación astronómica. El programa procesará los datos ingresados y mostrará un resumen de la actividad. El programa evolucionará en versiones posteriores utilizando los conceptos aprendidos en el curso.
